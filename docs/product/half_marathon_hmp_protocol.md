# 半程马拉松 HMP 百分比训练核心协议

> 目的：将《Sub-70 半程马拉松训练：一种基于百分比的系统化方法》沉淀为训练计划生成系统的核心规则层。
> 当前状态：第一阶段协议草案，仅作为规则、模板和验证依据；尚未强制接入主训练计划生成链路。

## 1. 核心定位

这份协议不是要求所有跑者照搬 Sub-70 运动员的跑量和课表容量，而是继承其底层方法：

- 以目标半马配速（HMP, Half Marathon Pace）为中心定义训练强度。
- 用阶段化训练把基础能力、辅助能力和专项能力串联起来。
- 用跑者画像决定训练侧重点，而不是套用固定模板。
- 用关键课表的进阶完成度判断是否具备比赛能力。
- 用安全约束防止计划超出跑者当前承受能力。

## 2. HMP 百分比强度体系

| 区间 | 名称 | 主要用途 | 典型课表 |
|---|---|---|---|
| <=55% HMP | 极轻松恢复 | 恢复、赛后导入、低压补跑量 | 极轻松跑、恢复跑 |
| 60-70% HMP | 轻松跑 | 日常有氧、跑量积累 | 轻松跑 |
| 75-85% HMP | 中等强度 | 有氧基础、稳定跑、渐速跑前段 | 中等跑、渐速跑 |
| 90% HMP | 辅助耐力 | 支撑 95% HMP 长距离快跑 | 稳定长跑、分段递进跑 |
| 95% HMP | 专项耐力 | 半马后程抗疲劳、接近全马配速能力 | 长距离快速跑 |
| 100% HMP | 核心专项 | 半马目标配速代谢效率 | 长间歇 + 巡航恢复 |
| 105% HMP | 专项速度 | 8K/10K 配速储备，让 HMP 更轻松 | 中长间歇、短程快速持续跑 |
| 107-110% HMP | 辅助速度 | VO2max、乳酸转运、速度上限 | 法特莱克、短间歇、5K 比赛 |

## 3. 阶段模型

### 3.1 导入期

适用对象：

- 刚比完全马或其他大赛。
- 久疏战阵，需要重新找回训练节奏。
- 近期疲劳、伤病、心理压力较大。

目标：

- 恢复身体和精神能量。
- 重新引入上一个周期缺失的能力。
- 使用体感训练多于精确配速训练。

常用课表：

- 极轻松跑。
- 森林小径/越野轻松跑。
- 短法特莱克。
- 坡冲或短坡重复。
- 肯尼亚式渐速跑。

### 3.2 基础阶段

目标：

- 稳步提升总跑量。
- 建立覆盖多配速区间的宽厚体能基础。
- 发展阈值、有氧功率、跑步经济性和基础耐力。

常用课表：

- 轻松跑和长距离轻松跑。
- 阈值训练。
- 中等强度长距离跑。
- 渐速跑。
- 法特莱克。
- 坡地训练。
- 跨步跑。

### 3.3 专项能力构建阶段

目标：

- 建立 90-95% HMP 的耐力支撑。
- 建立 105-110% HMP 的速度支撑。
- 为比赛专项阶段的大课铺垫。

常用课表：

- 90% HMP 长距离稳定跑。
- 95% HMP 较短距离快速跑。
- 105% HMP 中长间歇。
- 107-110% HMP 法特莱克。
- 带巡航恢复的中等间歇。

### 3.4 比赛专项阶段

目标：

- 最大化 95-105% HMP 区间能力。
- 逐步逼近比赛日需求。
- 在赛前 10-15 天左右完成关键 100% HMP 核心课。

关键课表：

- 95% HMP 长距离快速跑，理想上限约 20-25 公里。
- 100% HMP 长间歇 + 85-90% HMP 巡航恢复，理想累计 HMP 跑量约 14-15 公里。
- 105% HMP 中长间歇，理想累计约 8-10 公里。

## 4. 跑者画像原型

| 原型 | 典型特征 | 核心风险 | 计划侧重点 |
|---|---|---|---|
| A 型：耐力强、速度需重建 | 越野、超马、全马背景；长距离耐力扎实 | 忽视速度和有氧功率 | 从短距离快速跑、坡跑、法特莱克入手，逐步回到半马专项速度 |
| B 型：全马经验强但久疏战阵 | 路跑经验丰富，近期缺少系统训练 | 有氧功率不足，专项速度跟不上 | 拉长基础期，补阈值、短间歇、105-110% HMP 能力 |
| C 型：备战期短且刚比完全马 | 全马后快速转半马 | 过早安排高消耗课表，精神和身体未恢复 | 先恢复和导入，后期集中安排少量关键专项课 |
| D 型：速度强、半马耐力不足 | 1500 米/5K 背景，中距离能力强 | 无法长时间维持高速，巡航恢复经验不足 | 逐步加长快速跑距离，把速度转化为持久力 |

## 5. 关键课表库

| 课表 ID | 名称 | 目标区间 | 主要能力 |
|---|---|---:|---|
| `hm_90_support_endurance` | 半马辅助耐力跑 | 90% HMP | 支撑 95% HMP 长距离快速跑 |
| `hm_95_long_fast_run` | 半马专项耐力长距离快速跑 | 95% HMP | 后程抗疲劳、脂代谢、比赛耐力 |
| `hm_100_float_intervals` | 半马核心专项巡航恢复间歇 | 100% HMP + 85-90% HMP | 目标配速代谢效率、乳酸转运 |
| `hm_105_specific_speed` | 半马专项速度间歇 | 105% HMP | 8K/10K 速度储备 |
| `hm_110_support_speed` | 半马辅助速度训练 | 107-110% HMP | VO2max、速度上限、乳酸氧化 |
| `hm_intro_fartlek_hills` | 导入期法特莱克/坡跑 | 体感控制 | 恢复训练热情，重新引入速度 |
| `hm_base_threshold_progression` | 基础期阈值/渐速跑 | 阈值至中等强度 | 有氧功率、SSmax、跑步经济性 |

## 6. 进阶规则

### 6.1 95% HMP 专项耐力

进阶方向：

1. 短距离 95% HMP 快速跑。
2. 90% HMP 辅助耐力或中等强度长跑。
3. 分段递进跑，末段触及 95-97% HMP。
4. 长距离 95% HMP 快速跑。

理想上限：

- 高水平跑者可逐步接近 13-15 英里（20-25 公里）。
- 普通跑者必须按周跑量、训练年限和恢复情况缩放容量。

### 6.2 100% HMP 核心专项

进阶方向：

1. 1 公里 @100% HMP + 1 公里巡航恢复。
2. 2 公里 @100% HMP + 1 公里巡航恢复。
3. 3 公里 @100% HMP + 1 公里巡航恢复。
4. 组合式长间歇，例如 3-2-1-3-2-1 公里。

理想上限：

- 累计 14-15 公里 HMP 跑量。
- 单次训练总里程约 20 公里。

### 6.3 105% HMP 专项速度

进阶方向：

1. 500-1000 米短间歇。
2. 1200 米至 2 公里间歇。
3. 2-3 公里中长间歇。
4. 6-8 公里快速持续跑或 8K/10K 比赛。

理想上限：

- 累计 8-10 公里。
- 单次间歇长度 1-3 公里。

### 6.4 107-110% HMP 辅助速度

进阶方向：

1. 短坡冲刺或跨步跑。
2. 1-2 分钟短法特莱克。
3. 3-4-5 分钟混合法特莱克。
4. 400-1000 米间歇。

注意：

- 对耐力型跑者，名义 110% HMP 经常需要按当前 5K 能力下调到约 107-108% HMP。
- 该区间不宜机械套用，必须结合当前短距离能力判断。

## 7. 安全约束

| 约束 | 说明 |
|---|---|
| 不照搬 Sub-70 跑量 | 70-90 英里/周是高水平案例，不是普通跑者默认目标。 |
| 刚比完全马需导入 | 刚比完全马后，不应立即安排长距离 95% HMP 快跑。 |
| 关键课间隔恢复 | 高质量课之间应有充分恢复，通常至少 48 小时。 |
| 长距离快跑需进阶 | 不应从短距离训练直接跳到 20-25 公里 @95% HMP。 |
| 核心专项不宜过早极限化 | 100% HMP 大课应建立在支撑能力之上，通常靠近比赛专项后段。 |
| 配速百分比需动态校准 | 长周期中，当前 HMP 估计会变化，不能死守最初目标配速。 |
| 伤病或疲劳优先降级 | 出现伤病、持续疲劳、睡眠差或主观压力高时，应降低强度或改为体感课。 |
| 关键课容量需按画像预算 | 95/100/105% HMP 的累计量必须按周跑量、训练频率和恢复状态缩放，不能直接套用 Sub-70 理想上限。 |

## 8. 后续接入方式

第一阶段只落地协议和机器规则。后续建议分三步接入：

1. 将 `half_marathon_protocol.py` 接入半马计划骨架生成，用于确定阶段目标和关键课表候选。
2. 将关键课表 ID 注册到每日课表模板库，让 UI 能显示证据、目标和替代方案。
3. 在计划校验器中加入 HMP 专项约束，防止过早、过量或无证据的半马专项安排。

## 10. 容量预算落地规则

为了把“不要照搬 Sub-70 跑量”从提醒推进为可执行规则，系统新增 HMP 容量预算层：

- 输入当前周跑量、阶段、可训练日数量、近期全马/疲劳/伤病状态和速度校准可用性。
- 输出每周质量课上限、长距离上限、95% HMP 上限、100% HMP 累计上限、105% HMP 累计上限和 107-110% HMP 速度刺激上限。
- 导入期默认屏蔽 95/100/105% HMP 硬课容量。
- 低跑量、可训练日少、近期全马、疲劳/伤病或缺少 5K/10K 校准时，自动下调 HMP 关键课容量。
- 生成器必须先读取容量预算，再决定 100% HMP 的组数、105% HMP 的单段距离和速度刺激总量。
- 验证器发现实际课表超过容量预算时，输出 `capacity_budget_exceeded`；修复器可将超额课降级为 90% HMP 支撑跑。
