## 阶段一：修复短计划基础期间歇跑 🔴

### 问题

当前 `_build_quality_session()` 在短计划（<20周）基础期 fallback 中直接允许间歇跑：

```python
elif "基础" in phase_name:
    options = [
        ("节奏跑", ...),
        ("间歇跑", ...),      # ❌ 基础期不应有间歇跑
        ("无氧阈跑", ...),
    ]
```

但网上共识：基础期核心是有氧容量建立，高强度间歇应在建设期才引入。

### 改法

**[training_plan_skeleton.py](file:///c:/Users/26318/Documents/trae_projects/ollama_pro/马拉松助手/marathon_qa_assistant/core/training_plan_skeleton.py)** `_build_quality_session()` 中：

将基础期 fallback 的 options 从 `[节奏跑, 间歇跑, 无氧阈跑]` 改为：
```python
options = [
    ("有氧阈值训练", ...),
    ("节奏跑", ...),
    ("渐进跑", ...),
]
```
与长计划 `base_1` 的风格保持一致。

同时基础期的 `_build_secondary_session` 默认保持轻松跑（不再在基础期的偶数周自动排节奏跑——基础期应该以轻松的次课运营为主）。

### 验证

- 生成短/中/标准计划的 20 周训练方案，确认前 6 周（基础期）无间歇跑
- 已有 `test_20_week_half_marathon_volume_constraint_all_weeks` 通过后仍保持通过

## 阶段二：补齐缺失训练类型 🟡

### 2.1 新增法特莱克 (fartlek)

**网上依据：** RunnersWorld 推荐基础期后期/建设期前期引入法特莱克，作为"非结构化的速度游戏"，低心理压力、高有氧刺激。

**改法：**

1. **[training_plan_models.py]** `TRAINING_DISTANCE_FRACTIONS` 新增：
```python
"法特莱克": (0.10, 0.20),   # 与节奏跑类似，距离占比 10-20%
```

2. **[training_plan_skeleton.py]** `FIXED_WARMUP_COOLDOWN` 等效处理（法特莱克归 quality）。

3. **[training_plan_skeleton.py]** `_build_quality_session()` 在长计划 `base_2` 和短计划 `base` 阶段 option pool 中加入法特莱克。

4. **[workout_template_retriever.py]** `WORKOUT_TEMPLATE_REGISTRY` 新增：
```python
"fartlek": {
```

## 阶段三：补齐动作库的 cooldown + alternative 提取 🟡

### 问题

当前 `workout_template_retriever.py` 的 `evidence_status` 中 `cooldown` 和 `alternative_workout` 始终硬编码为 `"missing"`：

```python
# L241-242
"cooldown": "missing",
"alternative_workout": "missing",
```

这意味着即使动作库 PDF 中有冷身内容，也无法被提取和展示。

### 改法

1. 在 `build_daily_workout_template_card_from_hits()` 中加入冷身提取逻辑，参考已有的 `_extract_generic_warmup()` 模式，新增：
```python
def _extract_generic_cooldown(text: str) -> str:
    normalized = _clean_text(text)
    cooldown_patterns = [
        r"(?:冷身|cooldown|cool[-_ ]?down)[:：]\s*(.{5,80}?)(?:\n|【|$)",
        r"(?:冷身|cooldown|cool[-_ ]?down)\s+(.{5,60}?)(?:\n|$)",
        r"(\d+分[钟]?\s*慢跑\s*[\+＋]\s*拉伸.{3,60}?)",
    ]
    ...
```

2. 加入备选训练建议的提取逻辑（若当前课表不可用时的降级方案）。

3. 更新 `evidence_status` 字段为实际提取结果。

## 阶段四：短中计划次课 phase 感知化 🟠

### 问题

`_build_secondary_session()` 在非长计划路径下只做简单的"偶数周节奏跑/奇数周轻松跑"交替，不感知当前阶段。

### 改法

1. 给 `_build_secondary_session()` 传入 `mesocycle` 或 `phase_family` 参数。

2. 按 phase 区分次课策略：
   - **base**: 始终轻松跑（保留有氧容量，避免过早堆强度）
   - **build**: 偶数周节奏跑、奇数周法特莱克/渐进跑（增加变化）
   - **peak**: 偶数周 MP、奇数周渐进跑（专项化）
   - **taper**: 始终轻松跑（减量）

## 风险与边界

- 新增训练类型后，`_build_quality_session()` 的 option pool 变多，需确保每周 3 个候选的轮换不重复
- 法特莱克的 `TRAINING_DISTANCE_FRACTIONS` 区间较宽（10-20%），需要确认在 4 日高负荷模式下不会挤占轻松跑
- 坡道训练距�离占比小（6-12%），需要搭配额外的 warmup 和 cooldown 补齐日总跑量
- 动作库 PDF 若无对应冷身内容，cooldown 仍会返回空——属于正常降级
