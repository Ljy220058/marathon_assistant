\section{Experimental Setup}

\subsection{Systems and Models}

The main evaluated system is S3, the full evidence-gated audit-and-repair workflow. The primary model is \texttt{qwen2.5:latest}; \texttt{llama3:latest} and \texttt{deepseek-v4-pro} are supplementary 40-question sanity checks, not evidence of broad model generalization.

\subsection{Primary Runs}

The primary 100-question main benchmark uses \texttt{qwen2.5:latest} with \texttt{retrieval\_plus\_gold} and pre-gate off. The safety stress suite uses \texttt{qwen2.5:latest} and \texttt{llama3:latest} with \texttt{retrieval\_only} and \texttt{hardening\_v0\_4}. The supplementary 40-question subsets use the same balanced qids and \texttt{retrieval\_plus\_gold}.

\subsection{v0.3 Ablation Subset}

We also ran a balanced 40-question v0.3 subset ablation with \texttt{qwen2.5:latest}. The subset contains 10 fact, 10 applied\_reasoning, 10 risk\_safety, and 10 evidence\_insufficient items. It is the same balanced qid set used for the supplementary model sanity checks. Three ablations are reported: \texttt{no\_gate}, \texttt{no\_audit}, and \texttt{no\_repair}.

\subsection{Metrics}

Primary output statuses are \texttt{answered}, \texttt{partial\_answer}, and \texttt{refused}. Diagnostic metrics include designed-unanswerable refused, verified-answerable \texttt{false refusal}, \texttt{citation repair} count, pre-gate rule counts, average latency, and average evidence contexts.

\subsection{Anonymized Reproducibility Artifacts}

The review submission uses anonymized artifact identifiers rather than local file-system, user, or repository paths. The artifact index records each dataset, run id, model, evidence mode, pre-gate mode, prompt template version, output trace, and evaluation script. Reported runs include the 100-question qwen trace, qwen/llama3 stress traces, llama3 and DeepSeek 40-question subsets, and qwen ablations. All S3 runs use \texttt{s3\_full\_workflow\_v0.2} and \texttt{run\_stai\_s3\_full\_workflow.py}; exploratory runs are excluded.
