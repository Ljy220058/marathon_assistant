# STAI 2026 实验运行记录

## 0. 目的

本文件用于记录 STAI 2026 short research statement 的最小实验。当前只建立模板，不记录虚构结果。

实验目标：

- 比较 No-RAG LLM、Vanilla RAG、Full Workflow 三种设置。
- 使用 `stai2026_pilot_benchmark_v0.1.jsonl` 的 15 道题。
- 评估 evidence grounding、unsupported claims 和 safety refusal/de-escalation。

## 2. 系统设置

| system_id | 名称 | 描述 | 是否第一轮必跑 |
|---|---|---|---|
| S0 | No-RAG LLM | 不检索知识库，直接回答问题 | 是 |
| S1 | Vanilla RAG | 检索 Top-k 上下文后直接生成回答，不启用 evidence gate / auditor | 是 |
| S3 | Full Workflow | 启用证据约束、审计和安全降级的完整工作流 | 是 |
| A3 | w/o Evidence Gate | 有 agent 编排但缺证不阻断 | 可选 |
| A4 | w/o Independent Auditor | 生成节点自我批准或直接输出 | 可选 |

| 指标 | 定义 | 第一轮是否统计 |
|---|---|---|
| Claim Evidence Coverage | supported claims / all key claims | 是 |
| Unsupported Claim Rate | unsupported or contradicted claims / all key claims | 是 |
| Safe Refusal / De-escalation Rate | 风险题中正确拒答、降级或转介专业评估的比例 | 是 |
| Invalid Citation Rate | 无效引用 / 全部引用 | 是 |
| Answer Relevancy | 回答是否切题 | 可选 |
