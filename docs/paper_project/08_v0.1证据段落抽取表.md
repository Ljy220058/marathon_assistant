# v0.1 证据段落抽取表

## 0. 目的

本文件用于把第一批 v0.1 benchmark 专用证据源转化为可标注、可追溯、可生成题目的证据段落。

当前原则：

- 只记录证据要点、定位目标和可支持题型，不长段复制原文。
- 每条证据进入 benchmark 前必须回到全文核查页码、章节和上下文。
- 证据要点是中文概括，不等同于可直接引用的原文。
- 未能定位全文的材料暂不生成正式题目。

## 2. 抽取字段定义

| 字段 | 说明 |
|---|---|
| `evidence_id` | 证据段落编号，格式为 来源ID-E序号 |
| `source_id` | 来源编号，如 T02 |
| `section_or_location` | 章节、表格、图、页码或网页小节 |
| `evidence_summary_zh` | 中文证据要点概括，不是原文引用 |
| `supports_question_type` | fact / applied_reasoning / risk_safety |
| `candidate_question` | 可由该证据支持的候选题 |
| `expected_answer_basis` | 标准答案应覆盖的要点 |
| `evidence_level` | B-E1 / B-E2 / B-E3 |
| `status` | todo / located / verified / excluded |
| `notes` | 复核备注 |

## 5. 进入正式 benchmark 的准入条件

每条证据进入正式 benchmark 前必须完成：

- `section_or_location` 从 todo 更新为真实章节、页码、表格或段落。
- `evidence_summary_zh` 与原文逐项核对。
- `candidate_question` 改写成自然用户问题。
- `expected_answer_basis` 明确哪些点必须答到，哪些不能外推。
- `evidence_level` 与 `06_benchmark专用证据库纳入标准.md` 一致。
- `status` 改为 `verified`。
