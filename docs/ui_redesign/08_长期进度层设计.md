# 长期进度层设计（产品级细化版）

## 1. 文档目的

本文档定义马拉松助手长期进度层的产品级设计。长期进度层负责让用户看到自己在完整马拉松训练周期中的位置、进展和阶段变化，把马拉松助手从"一次性训练计划生成器"升级为"长期训练陪伴系统"。

## 2. 模块定位

长期进度层尤其服务于 4/8/12/20 周甚至更长计划的持续体验。它让用户感知到：我不是每次打开系统都重新开始，而是处在一个连续的训练旅程中。

## 3. 用户场景

### 3.1 场景 A：想知道自己在哪

用户拿了 12 周计划，训练了两周，想确认进度。

困惑：我现在在第几周？当前阶段还剩几周？下一阶段是什么？

### 3.2 场景 B：回顾已完成

用户完成了 4 周基础期，想回顾这段时间的训练。

困惑：基础期完成了吗？效果怎么样？进入建设期要注意什么？

### 3.3 场景 C：长计划不迷路

用户拿了 20 周计划，怕中途忘记整体方向。

困惑：我现在到哪了？离比赛还有几周？

### 3.4 场景 D：计划被调整过

用户反馈了几次疲劳，系统调整了计划，想知道调整历史。

困惑：计划改过吗？为什么改？原始计划是什么样的？

## 4. 信息架构

```text
长期进度面板
├── 总周期进度（进度条：第 5 周 / 20 周）
├── 当前阶段标识（"建设期 · 第 2 周"）
├── 阶段时间轴
│   ├── [基础期 W1-W4] ✅ 已完成
│   ├── [建设期 W5-W10] 🔵 进行中
│   ├── [巅峰期 W11-W16] ⬜ 待开始
│   └── [减量期 W17-W20] ⬜ 待开始
├── 已完成周摘要（可展开查看）
├── 后续周概览（收缩态）
└── 调整记录（如有）
```

## 5. 组件拆分

### 5.1 周期进度条（CycleProgressBar）

- 位置：长期进度面板顶部
- 类型：CustomElement（Progress + 标签）
- 职责：展示总周期进度
- 展示：`第 5 周 / 20 周 ████░░░░░░░░░░░░ 25%`

### 5.2 阶段时间轴（PhaseTimeline）

- 位置：进度条下方
- 类型：CustomElement（React 组件，横向步骤条）
- 职责：可视化阶段划分和当前所在阶段
- 每阶段展示：名称、起止周、状态（已完成/进行中/待开始）
- 交互：点击已完成阶段 → 查看该阶段摘要

### 5.3 已完成周列表（CompletedWeeksList）

- 位置：阶段时间轴下方
- 类型：折叠列表
- 职责：回顾已完成训练
- 每项：周编号 + 阶段 + 完成度 + 关键训练摘要
- 点击展开 → WeekTrainingCard

### 5.4 调整记录（AdjustmentHistory）

- 位置：长期进度面板底部
- 类型：折叠区
- 职责：记录计划调整历史
- 每项：日期 + 调整内容 + 调整原因
- 默认折叠，避免信息过载

### 5.5 阶段复盘卡（PhaseReviewCard）

- 位置：阶段完成后展示
- 类型：CustomElement
- 职责：总结已完成阶段
- 内容：阶段目标达成度、关键数据、下一阶段展望

## 6. 交互流程

```text
[入口层 → 长期进度入口] → CycleProgressBar → PhaseTimeline
                          → 用户可：
                              ├── 点击已完成阶段 → 查看阶段复盘
                              ├── 点击已完成周 → 展开 WeekTrainingCard
                              └── 展开调整记录
```

## 7. 状态设计

- 加载态：骨架屏
- 空态：无计划时不展示长期进度入口
- 正常态：阶段时间轴 + 进度条
- 异常态：计划数据异常时降级为文本展示

## 8. 与 Option A 架构的关系

- 数据来源：`structured_report.training_plan_weeks`、反馈累计、自适应调整记录
- FastAPI 端点（新增）：`/progress/{user_id}` GET

## 9. Astro 落地

- CustomElement：CycleProgressBar、PhaseTimeline
- 文件：`public/elements/CycleProgressBar.jsx`、`public/elements/PhaseTimeline.jsx`

## 10. 与其他模块的关系

- **入口层** ← 进度摘要嵌入
- **训练计划层** ← 提供完整多周计划
- **训练反馈层** ← 反馈累计为完成度
- **数据状态层** ← 状态累计趋势

## 11. 暂不设计的内容

- 复杂时间轴图表
- 阶段对比分析
- 预测完成时间
