# Triage Labels

The engineering skills use five canonical triage roles. This repo currently maps them to the default GitHub label strings.

| Skill role | Repo label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting on reporter or requester for more information. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent. |
| `ready-for-human` | `ready-for-human` | Requires human implementation or product judgment. |
| `wontfix` | `wontfix` | Will not be actioned. |

If the GitHub repository later adopts a different label vocabulary, update the right-hand column here before using triage automation.
