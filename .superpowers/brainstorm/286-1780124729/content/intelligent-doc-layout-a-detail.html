设计原则映射

  • NN/g Dashboard Design：核心任务前置，状态摘要清晰，避免把引用列表变成噪声。
  • Microsoft / Google Human-AI：明确 AI 能力边界，证据不足时主动提示。
  • WCAG 2.2：信息不只依赖颜色；提示、折叠按钮和状态文本均可读。
  • Carbon / TDesign / Material 3：卡片分区、层级清晰、状态标签明确、移动端可纵向堆叠。
  • Linear Method：单一主路径：提问 → 答案 → 展开依据 → 继续追问。
