# STAI Anonymous Source Package

This package contains the anonymous LaTeX source for the current STAI workshop submission.

## Recommended Build

Use `main_8p.tex` as the compact submission entry point.

The package includes:

- `main_8p.tex`
- `main.tex`
- `references.bib`
- `llncs.cls`
- `splncs04.bst`
- `sections/`
- `figures/figure1_method_workflow_nature.pdf`
- `figures/figure1_method_workflow_nature.svg`
- `figures/figure1_method_workflow_nature.png`

The review manuscript is anonymized in the PDF source:

- author: `Anonymous Author(s)`
- affiliation: `Paper under double-blind review`

Build outputs, local logs, local absolute paths, experiment run directories, and unrelated project files are intentionally excluded from this source package.
