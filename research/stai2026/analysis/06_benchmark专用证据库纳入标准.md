# Benchmark 专用证据库纳入标准

## 0. 目的

本文件定义第一版 benchmark 专用证据库的纳入、排除和分级标准。目标是建立一个“小而硬”的证据库，用于支撑 30-50 题耐力训练 RAG pilot benchmark。

当前优先范围：

- 第一批：耐力训练主题 + 风险安全主题。
- 第二批：营养与恢复主题。
- 暂不纳入：泛泛训练博客、商业训练计划、来源不清的 OCR、无法追溯页码的二手资料。

## 1. 核心原则

- 证据库服务于 benchmark，而不是产品知识库；宁可少，也要可追溯。
- 每个材料必须能定位到题目、答案和证据段落。
- 同行评议论文、官方指南和立场声明优先。
- 高质量训练手册只在学术证据无法覆盖实践问题时补充。
- 所有材料进入 benchmark 前必须登记元数据，不允许只凭文件名使用。

## 2. 纳入标准

### 2.1 主题范围

第一批纳入以下主题：

| 主题 | 可覆盖题型 | 示例 |
|---|---|---|
| 周期化与训练结构 | 事实抽取、应用推理 | microcycle、mesocycle、taper、训练分期 |
| 强度分布与强度分区 | 事实抽取、应用推理 | low-intensity volume、polarized/pyramidal training、threshold |
| HIIT/MICT 与训练刺激 | 事实抽取、应用推理 | HIIT 编排、跑步经济性、VO2max、耐力表现 |
| 训练负荷监控 | 应用推理、风险安全 | internal/external load、session-RPE、疲劳监测 |
| 跑步伤病风险 | 风险安全 | 训练负荷变化、跑量增长、既往伤病、过度使用伤 |
| 过度训练与恢复不足 | 风险安全 | overreaching、overtraining syndrome、恢复不足 |
| 热环境与运动性热病 | 风险安全 | 热衰竭、运动性中暑、热适应、补水降温 |
| 心血管与运动前筛查 | 风险安全 | 异常心率、心血管病风险、运动前评估 |

### 2.2 文献类型

优先纳入：

| 类型 | 优先级 | 说明 |
|---|---|---|
| 系统综述 / Meta-analysis | P0 | 适合生成稳定事实题和证据综述题 |
| 官方指南 / 立场声明 / 共识声明 | P0 | 适合风险安全题和拒答边界 |
| 高质量综述 | P1 | 适合训练方法、强度分布和机制解释 |
| 经典实证研究 | P1 | 适合作为特定事实或方法依据 |
| 教练协会或权威机构手册 | P2 | 只在实践细节缺口明显时补充 |

### 2.3 元数据要求

进入候选库时至少记录：

- 标题。
- 作者或机构。
- 年份。
- 发表源或发布机构。
- DOI、PMID、URL 或官方页面。
- 文献类型。
- 主题标签。
- 是否可获取全文。
- 是否适合公开 benchmark。

进入正式 benchmark 证据库前还必须补充：

- 页码或章节定位。
- 可引用段落。
- 证据等级。
- 版权/公开边界。
- 对应问题类型。

## 3. 排除标准

以下材料不得进入第一版 benchmark 专用证据库：

- 无法确认来源的 PDF。
- 文件头不是有效 PDF 或内容明显损坏的文件。
- 未经核查的 OCR 摘录。
- 商业训练计划、博客、论坛、视频字幕。
- 只包含作者观点但无可核查出处的材料。
- 与耐力训练或风险安全无关的运动项目材料。
- 不能支持明确问答样本的宏观评论。
- 涉及医疗诊断或治疗建议但不是医学指南、共识或专业综述的材料。

## 4. 证据分级

| 等级 | 定义 | Benchmark 用法 |
|---|---|---|
| B-E1 | 同行评议系统综述、meta-analysis、指南、立场声明、共识声明 | 可作为事实题、风险题和应用题的主证据 |
| B-E2 | 同行评议综述或经典实证研究 | 可作为主证据，但需注意适用人群 |
| B-E3 | 官方或权威机构手册 | 可作为实践边界证据，需标注非同行评议 |
| B-E4 | 项目内部规则或动作库 | 只用于系统规则测试，不用于外部科学结论 |
| B-E5 | OCR、摘录、灰色文献 | 暂不进入正式 benchmark |

## 5. 第一批证据库目标规模

建议第一批正式纳入：

- 8-10 篇耐力训练主题材料。
- 8-10 篇风险安全主题材料。
- 总计 16-20 个高质量来源。

每个来源理想支持 1-3 道题，避免单篇材料支撑过多问题。

第一版 36 题建议分配：

| 题型 | 数量 | 证据来源策略 |
|---|---:|---|
| 事实抽取 | 12 | 以 P0/P1 学术来源为主 |
| 应用推理 | 12 | 组合训练综述 + 指南/共识 |
| 风险安全 | 12 | 以共识声明、指南和伤病/热病综述为主 |

## 6. 纳入流程

1. 建立候选清单。
2. 标注优先级：P0 / P1 / P2 / 排除。
3. 核查元数据。
4. 判断能否获取全文和页码。
5. 抽取可支持题目的证据段落。
6. 登记到 `01_材料证据审计表.md`。
7. 生成 benchmark 样本。
8. 冻结证据库版本。

## 7. 当前决策

当前已确定：

- 优先补充 Benchmark 专用证据库，而不是通用产品知识库。
- 第一批使用“同行评议论文 + 官方指南/立场声明”。
- 必要时再补高质量训练手册。
- 第一批主题聚焦耐力训练与风险安全。
- 营养恢复主题作为第二批。
