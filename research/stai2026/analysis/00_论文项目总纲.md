# 论文项目总纲

## 0. 项目原则

本论文项目服务于当前“马拉松助手”仓库的长期科研化写作与投稿准备。所有研究结论必须来自可核查材料、可复现实验或明确标注的人工评审记录。

硬性约束：

- 不编造文献、页码、DOI、数据、实验结果或专家意见。
- 不把未审计的项目草稿直接写成论文事实。
- 不删除、不移动现有项目文件；论文工程优先新增和审计。
- 对知识库、PDF、OCR 文档、实验报告和代码输出进行分层管理。
- 所有实验结果必须记录模型、版本、参数、数据范围、运行日期和失败情况。

## 1. 当前定位

当前不预设为纯体育训练论文，而是优先面向人工智能、NLP 或信息系统方向收敛。

初步核心命题：

> 构建一个面向耐力训练场景的 evidence-constrained RAG 框架，并通过小规模高质量 benchmark 验证其在可追溯性、事实一致性和安全拒答方面的效果。

当前研究主线：

- 主贡献 1：证据约束 RAG 框架。
- 主贡献 2：耐力训练问答 pilot benchmark。
- 初始评测对象：RAG 问答入口。
- 第一版规模：30-50 题 pilot benchmark，后续扩展。
- 问题类型：事实抽取、应用推理、风险安全三类均衡。
- 对比基线：无检索 LLM、普通 RAG、证据约束 RAG。
- 模型环境：本地 Ollama 模型 + 一个主流 API 模型。
- 数据公开：第一版先私有 pilot，投稿前再决定公开范围。

## 2. 论文可能形态

### 2.1 推荐形态

AI / NLP / 信息系统方向的应用型 RAG 论文：

- 研究对象：耐力训练问答中的证据可追溯和安全性问题。
- 方法对象：证据约束 RAG 框架。
- 评测对象：小规模高质量 benchmark。
- 实验对象：不同问答系统设置下的检索、生成、证据追踪和安全表现。

### 2.2 暂不优先形态

以下方向暂不作为第一阶段主线：

- 单纯马拉松训练计划生成论文。
- 单纯系统介绍论文。
- 单纯用户效果或长期干预论文。
- 未建立真实标注和验证流程前的专家经验型论文。

这些方向可以作为后续扩展或第二篇论文素材。

## 3. 第一阶段目标

第一阶段目标不是直接写完整论文，而是建立可投稿工作的最小研究闭环。

交付物：

- 现有材料证据审计表。
- 30-50 题 pilot benchmark 设计。
- 可运行的实验矩阵草案。
- 一轮基线实验记录。
- 一份论文结构草案。

完成标准：

- 每个测试问题都有明确证据来源或明确标注为无证据问题。
- 每条标准答案能追溯到材料、文献或人工标注规则。
- 每个系统输出都有运行配置记录。
- 每个指标定义清楚，不混用不同口径。
- 论文中的每个主张都能在审计表或实验记录中找到出处。

## 4. 研究边界

当前论文第一阶段只覆盖 RAG 问答入口，不直接把多周训练计划生成作为主要评测对象。

纳入范围：

- 训练知识问答。
- 训练原则解释。
- 营养、恢复、风险提示等可基于材料回答的问题。
- 高风险问题下的安全拒答、降级建议或转介提示。

暂缓范围：

- 长周期用户真实训练效果。
- 临床或医疗结论。
- 未经验证的个体化训练处方效果。
- 无法复现实验环境的口头经验。

## 5. 长期路线

### Phase 1：材料审计与 benchmark pilot

- 盘点现有 PDF、OCR、技术文档、实验报告和代码输出。
- 建立可引证、可参考、仅内部背景三层材料边界。
- 设计 30-50 题 pilot benchmark。
- 明确标注流程和证据字段。

### Phase 2：实验链路与指标验证

- 实现或整理三类系统设置：无检索 LLM、普通 RAG、证据约束 RAG。
- 运行本地 Ollama 模型和一个主流 API 模型。
- 统计检索指标、生成质量、证据追踪和安全指标。
- 记录失败样例和错误类型。

### Phase 3：论文初稿

- 固化 Introduction、Related Work、Method、Benchmark、Experiments、Discussion 结构。
- 只写已被证据表和实验结果支持的结论。
- 将未完成内容明确标为 future work 或 limitation。

### Phase 4：投稿前强化

- 补充对比基线或更多测试题。
- 完成参考文献核查。
- 决定 benchmark 的公开范围。
- 按目标期刊格式调整论文。

## 6. 风险清单

- 现有材料混杂：学术论文、训练指南、OCR、项目技术文档不能混作同一证据等级。
- 现有 RAG 评估样本较少，不能直接支撑强结论。
- OCR 文档可能存在缺页、识别错误或来源不清。
- API 模型版本和输出可能变化，必须记录运行日期和模型标识。
- 体育训练建议涉及健康风险，论文需避免医疗化承诺。
- 若使用版权 PDF，公开数据集时需要拆分题目、答案、证据引用和原文内容。
